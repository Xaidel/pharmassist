# Application Documentation

This tree belongs to the Pharmassist POC application.

| Location | Owns |
| --- | --- |
| [`PRD.md`](PRD.md) | Product requirements and vision |
| [`poc/data-contract.md`](poc/data-contract.md) | POC schema, seed/wipe, HTTP API, privacy, and OCR swap contract |
| [`research/`](research/) | Research notes supporting the product decisions |
| [`agents/issue-tracker.md`](agents/issue-tracker.md) | Issue-tracker conventions |
| [`lessons/`](lessons/) | Gotchas and lessons recorded by contributors |
| [`specs/`](specs/README.md) | Normative requirements and technical designs for bounded slices |
| [`adr/`](adr/README.md) | Decisions specific to this application |

Material that must govern every application derived from the template belongs in [`../template_docs/`](../template_docs/architecture.md) and is recorded there with the `create-adr` lifecycle. Neither collection numbers its records: a record's path carries its lifecycle, its classification, and its first-proposed date, and its title is its name.

The placement rule, the full ownership table, and the identifier convention are stated once in the repository [README](../README.md#documentation-ownership).
